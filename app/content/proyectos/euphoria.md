## Contexto
Aplicación web personalizada para el "Salón de Belleza Euphoria", un cliente que busca digitalizar su experiencia de usuario.

## Problema
El salón carece de presencia online y los clientes no tienen forma de conocer los servicios o agendar sin llamar. Además, no hay un sistema de lealtad que incentive el retorno de los clientes frecuentes.

## Solución
Estoy construyendo una interfaz moderna y rápida que consume la API de Tiven. Incluye un catálogo de servicios, agenda en línea y un monedero electrónico donde los clientes acumulan puntos por cada visita.

## Qué hago yo
Como único desarrollador (**Solo Fullstack**), diseño y desarrollo todo el frontend utilizando NuxtJS y Vue 3. Integro la autenticación y los servicios de la API de Tiven para el manejo de los puntos y las citas.

## Decisiones técnicas
*   **NuxtJS/Vue 3:** Para aprovechar las capacidades de SSR y dar una sensación de fluidez extrema (App-like).
*   **TypeScript:** Para asegurar un desarrollo libre de errores comunes de tipado al consumir la API.
*   **Tailwind CSS:** Para lograr un diseño minimalista y profesional acorde a la marca.

## Retos
La integración del monedero electrónico de forma segura, asegurando que los puntos se reflejen correctamente consumiendo una API externa (Tiven).

## Resultado esperado
Un sitio web atractivo que permita al salón captar nuevos clientes a través de redes sociales y mejorar la fidelidad mediante el sistema de puntos.
